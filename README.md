# Coding Challenges

This repository contains a collection of coding challenges with various difficulty levels. These challenges are great for sharpening your problem-solving skills and preparing for coding interviews.

## 📚 Problem Set

### 1. String Manipulation

- **Reverse a String**: Implement a method to reverse a string without using built-in functions.
- **First Non-Repeating Character**: Given a string, return the first non-repeating character.
- **Anagram Check**: Write a function to check if two strings are anagrams of each other.
- **Generate All Subsets**: Given a string, generate all possible subsets (Power Set).

### 2. Array and Number Problems

- **Second Largest Number**: Write a function to find the second largest number in an array.
- **Remove Duplicates**: Remove duplicates from an integer array without using extra space.
- **Intersection of Two Arrays**: Return common elements between two unsorted arrays.
- **Find in Rotated Sorted Array**: Implement binary search on a rotated sorted array.

### 3. Object-Oriented Design

- **Library Management System**: Design classes for `Book`, `User`, and `Library` with methods like `borrowBook()` and `returnBook()`.
- **Singleton Class**: Write a thread-safe Singleton class.
- **Factory Design Pattern**: Implement a Factory Pattern for creating different types of bank accounts.

### 4. Algorithmic Challenges

- **N-Queens Problem**: Implement a solution for the N-Queens problem using backtracking.
- **Custom Sorting with Comparator**: Sort a list of objects using a custom comparator.
- **Trie (Prefix Tree)**: Implement a Trie with `insert()`, `search()`, and `startsWith()` methods.

### 5. System Design Challenges

- **URL Shortener**: Design a URL shortening service similar to Bit.ly with URL redirection.
- **Rate Limiter**: Implement a token bucket or leaky bucket algorithm to limit API requests.
- **Circuit Breaker Pattern**: Protect a service from excessive failures using a circuit breaker.

### 6. Multithreading and Concurrency

- **Thread-safe Singleton**: Ensure only one instance is created in a multi-threaded environment.
- **Producer-Consumer Problem**: Implement using `BlockingQueue` or `ReentrantLock`.
- **Simple Thread Pool**: Implement a basic thread pool executor.
- **LRU Cache**: Use `LinkedHashMap` or `ConcurrentHashMap` to implement an LRU (Least Recently Used) cache.

## 💡 Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/coding-challenges.git
    cd coding-challenges
    ```
2. Choose a challenge and create your implementation.
3. Run tests to validate your solution.
